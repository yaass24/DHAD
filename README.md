# ضاد | DHAD

**عِش الحكاية، واختر كلماتك.**

**ضاد** لعبة ويب تفاعلية لتعلّم اللغة العربية الفصحى من خلال القصص المصوّرة والمحادثات الواقعية، موجهة للأطفال والكبار.

## مسارات اللعبة

### حكايات ضاد — للأطفال
قصص يومية مصوّرة وملونة، تتطور أحداثها عندما يختار الطفل الكلمة المناسبة لإكمال الحوار. تتضمن مستويات ونقاطًا ومؤثرات صوتية وتشجيعًا عند الإجابة الصحيحة.

### مواقف ضاد — للكبار
محاكاة محادثات ومواقف حياتية ومهنية، مثل مقابلات العمل والاجتماعات والتفاوض وخدمة العملاء. يختار اللاعب التعبير الفصيح الأنسب للموقف ويتعرّف على سبب الاختيار.

## أبرز المميزات

- واجهة عربية بالكامل تدعم القراءة من اليمين إلى اليسار.
- قصص وحوارات تفاعلية مع اختيارات متعددة.
- مؤثرات صوتية وحركية للتغذية الراجعة.
- مستويات، نقاط، وإنجازات.
- حفظ التقدم داخل المتصفح.
- تصميم متجاوب مع الجوال والتابلت والكمبيوتر.
- لا تتطلب النسخة التجريبية حسابًا أو نموذج ذكاء اصطناعي.

## التقنيات المستخدمة

صُمّم الموقع باستخدام **React** و**TypeScript** و**Vite**. تُخزّن بيانات القصص والحوارات داخل ملفات المشروع، ويُحفظ تقدم اللاعب محليًا في المتصفح.

## تشغيل المشروع محليًا

بعد تحميل الملفات وتثبيت **Node.js**، افتح مجلد المشروع في الطرفية ونفّذ:

```bash
npm install
npm run dev
```

لإنشاء نسخة الإنتاج:

```bash
npm run build
```

## فكرة المشروع

يهدف ضاد إلى جعل ممارسة اللغة العربية الفصحى جزءًا من تجربة قصصية ممتعة، بدل الاكتفاء بالأسئلة المنفصلة. يقدّم للأطفال عالم حكايات مصوّرة، وللكبار مواقف حوارية تساعد على اختيار الكلمات والتعبيرات الملائمة للسياق.
